# Phases

## Theme Header
### Staged portfolio build plan

## Stage 0: Confirm requirements and content sources
- Review the PRD, design notes, rules, and prompt together.
- Confirm the exact section order and the source of truth for profile content.
- Identify any missing information in the attached profile PDF before moving ahead.
- Do not begin implementation until this stage is approved.

## Stage 1: Page structure only
- Create the section scaffold in the order given in the PRD.
- Include headings and placeholder blocks only.
- No styling, no real content, and no components.
- Stop after this structure is reviewed and approved.

## Stage 2: Visual design
- Apply the colours, typography, spacing, and hierarchy from the design documents.
- Keep the existing structure and placeholders intact.
- Do not add content, new components, or extra sections.
- Stop after the visual direction is reviewed and approved.

## Stage 3: Real content
- Replace the placeholders with content from the attached profile PDF only.
- Use only this content; if something is missing, leave the section empty and note what is missing.
- Do not add filler text or guessed details.
- Stop after the content is reviewed and approved.

## Stage 4: Final verification
- Check responsiveness, section flow, and accessibility.
- Confirm links, buttons, and CTA visibility work correctly.
- Review the site for clarity, completeness, and polish.
- Only proceed to launch or handoff after this final review.

## Theme headers
### Stage gating
Each stage is intentionally separate. Do not move to the next stage until the current stage has been reviewed and confirmed.
