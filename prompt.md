# Prompt

## Theme Header
### Portfolio build prompt

## Objective
Create a polished portfolio website for a developer that communicates projects, skills, education, and contact details clearly.

## Requirements
- Build a modern single-page portfolio.
- Include sections for About, Projects, Skills, Education, and Contact.
- Use a professional, calm color palette.
- Make the layout responsive and easy to navigate.
- Provide strong visual hierarchy and clear calls to action.

## Theme headers
### Content direction
Focus on a product-minded developer who combines technical skills with communication and practical execution.

### Visual style
Use deep navy backgrounds, blue accents, minimal decoration, and clean typography.

### Interaction guidance
Keep transitions smooth but subtle so the experience feels premium without distracting from the content.
