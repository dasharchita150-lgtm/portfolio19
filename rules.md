# Rules

## Theme Header
### Clear, fast, and recruiter-friendly

## Core rules
- Keep the website easy to navigate on both mobile and desktop.
- Prioritize clarity over decoration.
- Make every section answer a likely visitor question.
- Ensure contact actions remain visible and easy to use.

## Content rules
- Use concise copy with strong headings.
- Highlight the strongest project early.
- Keep skill lists easy to scan.
- Present education and background in a structured way.

## Technical rules
- Use responsive layouts and accessible color contrast.
- Ensure links and buttons work correctly.
- Keep the site lightweight and fast to load.
- Favor simple structure and maintainable code.

## Theme headers
### Navigation
Simple top-level links to About, Projects, Skills, Education, and Contact.

### Layout
Single-page structure with clear section separation and consistent spacing.

### Interaction
Subtle hover and motion effects only where they support clarity.
